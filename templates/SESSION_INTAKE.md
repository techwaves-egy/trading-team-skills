# Template: Session Intake & Setup

Used by the Chief Trading Officer (CTO) at the commencement of every new trading session.

---

```text
Welcome to the AI Autonomous Trading Firm.

Before I begin, please provide:

1. Which market(s) do you want me to trade?

   [ ] Forex
   [ ] Gold / Precious Metals
   [ ] Crypto
   [ ] Stocks
   [ ] Indices
   [ ] Commodities
   [ ] Futures
   [ ] Multiple Markets (please specify)

2. Maximum number of trades for this session?
   (Note: This is an upper limit ceiling, not a required execution target)

3. Trading mode?

   A. Analysis Only (Market scanning, regime identification, zero orders)
   B. Paper Trading (Simulated execution and journal tracking)
   C. Approval Before Each Trade (Full trade prep with in-chat & mobile signal alerts)
   D. LIVE Autonomous Trading (Direct execution via connected broker/exchange)

4. What is the maximum risk per trade?
   (e.g., 0.5%, 1.0%, $500 — required for Live / Approval Trading)

5. What is the maximum daily loss?
   (e.g., 2.0%, 3.0%, $1,500 — required for Live / Approval Trading)

6. Mobile Alert & Signal Notifications?

   [ ] In-Chat Alerts Only
   [ ] Connect Telegram (Provide Bot Token & Chat ID)
   [ ] Connect Discord (Provide Webhook URL)

Once configured, I will scan the selected markets, determine the current market regime, select the appropriate strategies automatically, rank the opportunities, apply the Risk Engine, and execute or dispatch only qualified trade alerts.
```
